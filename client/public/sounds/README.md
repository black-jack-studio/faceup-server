Drop your own `.ogg` (or `.mp3`) files here with these exact names — `client/src/lib/sound.ts` references them by path and needs nothing else changed:

- `card-deal.ogg` — a card sliding/being dealt
- `card-flip.ogg` — a card flipping face-up
- `chip-bet.ogg` — placing a chip/bet
- `shuffle.ogg` — deck shuffle
- `button-click.ogg` — tapping an action button (Hit/Stand/Double/Split/Surrender)
- `win.ogg` — hand won (incl. blackjack)
- `lose.ogg` — hand lost
- `push.ogg` — push/tie
